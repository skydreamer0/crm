# HPK 客戶資料填寫規則

## 完成標準

- 客戶是必要資料。CRM 的「拜訪對象」必須成功解析為真實 Lookup 記錄，才可儲存約會。
- 產品介紹明細是選填資料。產品新增失敗不會把已完成的客戶資料判定為失敗，但會保留警告供事後檢查。

## 名單格式

建議使用固定格式：

```text
醫院/科別/客戶/等級
光田/URO/王小明/A
```

只要第二段能識別為科別，解析器就會固定把第一段視為醫院、第三段視為客戶。因此 HPK 新醫院不需要先加入產品矩陣，也不會被誤判成客戶姓名。

## CRM 客戶選取

1. 以客戶姓名查詢 CRM 候選。
2. 有醫院資料時，候選必須同時包含相符醫院。
3. 科別用於同院同名候選的優先判斷。
4. 找不到候選或有多筆同分候選時停止該筆，不猜測、不儲存。
5. 選取後再次讀取 resolved Lookup，驗證通過才儲存約會。

此規則同時適用原區域與 HPK，不需要新增只有顯示用途的區域開關；實際可查詢的客戶範圍仍由登入 CRM 的帳號權限決定。
